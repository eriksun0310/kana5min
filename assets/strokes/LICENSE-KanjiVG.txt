KanjiVG stroke data attribution
================================

The kana stroke-order data used by this app (src/data/strokes.json) is derived
from KanjiVG.

  Project:    KanjiVG
  Website:    https://kanjivg.tagaini.net
  Source:     https://github.com/KanjiVG/kanjivg

  License:    Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0)
              https://creativecommons.org/licenses/by-sa/3.0/

Modifications: this project extracts only the hiragana and katakana glyphs
(plus the prolonged sound mark) from the KanjiVG SVG files, and converts the
stroke paths and stroke-number positions into a JSON file. The path data
itself is not otherwise altered. Generated by scripts/build-strokes.mjs.

Because the derived data is a modification of KanjiVG material, the file
src/data/strokes.json is distributed under the same license, CC BY-SA 3.0.
