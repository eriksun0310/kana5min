# 使用者旅程分析：我學到哪、下一步是什麼

2026-11-02。範圍：初學五十音的人，從打開 App 到畢業。依目前程式（首頁、練習頁、設定頁、新手導覽）整理。

## 一、現在 App 怎麼帶人走

| 階段 | 使用者看到什麼 | 夠不夠清楚 |
|---|---|---|
| 第一次打開 | 3 頁導覽（每天只學 3 個字、…、く＝哭的諧音）→ 選每天練多久 → 首頁 | 導覽講「概念」，沒講「按鈕按下去會發生什麼」 |
| 每天一輪 | 首頁大字＋「開始今天的 5 分鐘」→ 看、聽、寫、小測驗 | 按鈕只寫時間，沒寫內容；第一次不知道會進到什麼 |
| 學完一行 | 「一行學完」畫面 | 清楚 |
| 今天做完 | 首頁「今天完成了」，按鈕變灰 | **死路**：沒說明天會學什麼、今天還能做什麼 |
| 練習頁 | 自動練習、掉字歸類、最常搞混的、特殊音 | 卡片只有一行說明，文字已經過時（見下） |
| 平假名學完 | 片假名開始畫面 | 清楚，但之前看不到「還有片假名」 |
| 兩種都學完 | 畢業畫面、「下一步：壽司日檢」 | 清楚 |
| 卡住時 | 設定裡有「重看教學」 | 沒有常見問題、沒有聯絡方式 |

## 二、主要缺口

1. **沒有整條路線圖。** 首頁只說「學到〇行」。使用者不知道總共有幾個階段、現在在哪、片假名什麼時候來、練習頁什麼時候該去。
2. **「今天完成了」是死路。** 按鈕變灰就沒了。這時候最需要告訴使用者：明天會學哪 3 個字、什麼時候有字要複習、今天還想練可以去哪裡。
3. **進入點沒說「做什麼、得到什麼、要多久」。** 使用者回報「不知道點進去要做什麼、可以帶給我什麼」，對應到：
   - 首頁大按鈕（只有時間）
   - 練習頁的四張卡片
   - 易混淆字、特殊音（長音、促音、拗音）這些名詞初學者看不懂
4. **練習頁文字過時。** 自動練習寫「聽音選字、看字選音、找不同，10 題」，實際已經有 11 種題型（找出所有、念出一串、遮一半、默寫、看詞選拼音⋯）。
5. **沒有常見問題、沒有聯絡我們。** 設定頁的「關於」只有版本、重看教學、筆順資料、發音來源。
6. **進度的意思沒有說。** 「已學」「待複習」「今天新字」只在點開面板後才有解釋；「拼音為什麼會消失」只有一段小字。

## 三、建議（依價值排序）

### A. 首頁加一張「下一步」卡（最重要）

依狀態只講一件事，放在大字下面、按鈕上面：

| 狀態 | 卡片內容 | 按鈕 |
|---|---|---|
| 有新字 | 「今天學 あ、い、う（約 5 分鐘）：看字 → 聽音 → 寫筆順 → 小測驗」 | 開始今天的練習 |
| 有到期要複習 | 「有 4 個字要複習，隔太久會忘」 | 開始複習 |
| 今天都完成 | 「今天完成了！明天會學 か、き、く。還想練？去做易混淆字練習」 | 去練習頁（取代灰掉的按鈕） |
| 平假名剩最後一行 | 「再 5 個字就學完平假名，學完解鎖片假名」 | 開始今天的練習 |
| 兩種都學完 | 「五十音畢業！」 | 下一步：壽司日檢 |

### B. 「學習地圖」小條（首頁或五十音表上方）

一條橫的進度：平假名 ● ─ 片假名 ○ ─ 練習 ○ ─ 畢業 ○，目前階段高亮。點進去有一句話說明每個階段做什麼。

### C. 每個入口加「做什麼／得到什麼／多久」三行

練習頁四張卡片、特殊音、易混淆字目錄，第一次進入時顯示一次說明面板（沿用掉字遊戲的「怎麼玩」做法），之後在標題旁留「？」可再看。文字例：

- 自動練習：10 題，混合看字選音、聽音選字、默寫等；系統依你答錯的字出題。約 3～5 分鐘。
- 掉字歸類：字從上面掉下來，放進對的籃子；專門練長得很像的字。約 2 分鐘一關。
- 易混淆字：長得很像的字放在一起比較，並有記法；可以直接做快速辨識。
- 長音、促音、拗音：日文裡「拉長、停頓、合起來唸」的三種特別唸法，先聽再比較。

### D. 常見問題與聯絡（設定 → 幫助與聯絡）

- 常見問題（可摺疊）：
  1. 一天要學多少？（3 個新字，之後靠複習）
  2. 為什麼要先學平假名？
  3. 拼音為什麼不見了？（同一個字連續答對 3 次就會藏起來；在設定可以關掉）
  4. 為什麼自動練習鎖住？（完成今天第一輪練習後解鎖）
  5. 掉字歸類怎麼玩？
  6. 默寫怎麼判對錯？
  7. 沒有聲音怎麼辦？（靜音鍵、音量、耳機；設定裡可調發音速度）
  8. 提醒通知沒收到？（系統設定 → 通知）
  9. 進度會不會不見？（存在這支手機，換手機或刪除 App 不會自動帶走）
  10. 怎麼重看教學？
- 聯絡：
  - 信箱：connect.ptalk@gmail.com（點了開啟寄信，主旨與內文自動帶入 App 版本、系統版本與機型，方便回報問題）
  - Threads：@ptalk.design
  - 回報問題按鈕（同信箱，主旨「五十音問題回報」）

### E. 導覽改成「做給你看」

現有 3 頁導覽保留，但第 3 頁之後多一頁「一天會這樣走」：看字 → 聽音 → 寫筆順 → 小測驗，各一個小圖示與一句話；結尾的按鈕寫「開始第一天（約 5 分鐘）」。

## 四、需要你決定的事

1. 首頁「下一步」卡（A）要不要做？建議做，是最能解「不知道下一步」的一項。
2. 學習地圖（B）要不要？建議做簡版（一條進度），放首頁。
3. 常見問題的 10 題，哪些要留、哪些要改寫？回報問題要不要自動帶入裝置資訊（建議要）？
4. 每個入口的第一次說明（C）：用「第一次進入自動跳面板」還是「只放『？』按鈕」？（建議第一次跳一次、之後放 ？）
5. 聯絡方式要不要同時放在首頁的 ？說明裡？（建議只放設定，首頁說明底下放一個連結）

## 五、不用決定、我可以直接做的

- 練習頁自動練習的說明文字更新成實際內容。
- 「今天完成了」按鈕不再灰掉，改成帶使用者去練習頁。
